# Инвестбанк — кликабельный прототип

Прототип раздела «Инвестбанк» в интернет-банке «Совкомбанк Бизнес» для корпоративно-инвестиционного
бизнеса. Собран по вайрфрейму `Инвестбанк.pdf` и дополнен экранами, которых в нём не было.
Один файл — `index.html`, без сборки и бэкенда.

**Это демонстрационный макет.** Все цифры вымышлены, формы ничего не отправляют
и не сохраняют, сверху страницы висит предупреждающая плашка.

## Демо-переключатели

В тёмной плашке сверху два селектора — ими показывают разные состояния одного кабинета:

- **Клиент**: с портфелем (квалифицированный) · новый, без продуктов · с портфелем, но без статуса квала.
- **Роль**: казначей (готовит документы) · руководитель (подписывает). Роль меняет кнопки
  на подтверждении платежа и на заявке.

Прямые адреса для показа: `#/persona/qual`, `#/persona/new`, `#/persona/notqual`.

## Экраны

| Экран | Адрес |
| --- | --- |
| Главная «Инвестбанка» | `#/` |
| Главная для клиента без продуктов | `#/persona/new` → `#/` |
| Структура портфеля | `#/portfolio` |
| Брокерское обслуживание, разрезы | `#/portfolio/broker/assets` · `/sectors` · `/currency` · `/countries` |

| Статус квалифицированного инвестора | `#/qual` |
| Лендинг: брокерское обслуживание | `#/product/broker` |
| Лендинг: выпуск облигаций | `#/product/bonds` (табы `/coupon`, `/period`) |
| Лендинг: выход на IPO | `#/product/ipo` |
| Заявка на консультацию | `#/apply/broker` · `#/apply/bonds` · `#/apply/ipo` |
| Заявка принята | `#/apply/broker/done` |

Состояние живёт в адресной строке — ссылку на конкретный экран можно отправить отдельно.
Пункты левого меню вне прототипа ведут на общую заглушку «Этого экрана нет в прототипе».

## Что взято из практики корпоративных ДБО

- Двухступенчатое подтверждение: казначей готовит платёж, руководитель подписывает.
- Назначение платежа формируется банком и не редактируется — от него зависит зачисление.
- Перед подтверждением показан остаток после перевода и срок зачисления.
- Квитанция с номером документа и статусом вместо простого «Готово».
- Заявка — таймлайн стадий с явным блоком «нужно от вас» и персональным менеджером.
- История операций: фильтры, итоги за период, статусы, выгрузка XML для 1С.
- Статус квала: инструменты не прячутся, а помечаются замком с объяснением и путём получения.

## Посмотреть локально

Открыть `index.html` в браузере — больше ничего не нужно.
